# Tuki 🦜 – לימוד אנגלית

אפליקציה ללימוד אנגלית שמותאמת לרמה שלך.

## מה יש באפליקציה
- 🎯 מבחן רמה ורמה שמשתנה אוטומטית (A1 עד C1)
- 📚 אוצר מילים עם הקראה, זיהוי דיבור וחזרה מרווחת
- 🧩 השלמת משפטים עם הסבר בעברית
- 🔁 תרגום עברית ⇄ אנגלית
- 🎧 הכתבה, 👂 הגייה (ship/sheep) ו-🦜 Shadowing
- 💬 מורה AI, 📝 תיקון כתיבה ו-📖 סיפורים
- 📒 מחברת טעויות ו-📈 מעקב התקדמות

## התקנה בטלפון
פותחים את האתר ובוחרים **שיתוף ← הוספה למסך הבית**.
